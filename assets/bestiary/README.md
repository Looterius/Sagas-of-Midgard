# Bestiariusz — ilustracje

Tu wrzucaj obrazy **potworów i istot, które gracze już poznali**, np. `backahast.png`, `draugry.webp`, `harald-hardrada.png`, `zjawy.png`.

Dopuszczalne formaty: PNG, JPG/JPEG i WebP. Zalecane: proporcje portretowe (np. 3:4), czytelna wysoka rozdzielczość, małe litery w nazwie, myślniki zamiast spacji i brak polskich znaków.

**Uwaga:** folder jest publiczny. Nie dodawaj ilustracji zdradzających przyszłe spotkania, tożsamość ukrytego przeciwnika ani inne sekrety Skalda — nawet gdy nie są jeszcze podłączone do strony. Dodanie pliku nie oznacza automatycznego wyświetlania w Bestiariuszu; obraz wymaga przypisania do potwierdzonego ID wpisu.

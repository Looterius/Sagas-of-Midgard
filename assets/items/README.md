# Przedmioty i artefakty — ilustracje

Tu wrzucaj obrazy **przedmiotów, które gracze już odkryli**, np. `gungnir.png`.

Dopuszczalne formaty: PNG, JPG/JPEG i WebP. Zalecane: obiekt na czytelnym tle, rozdzielczość co najmniej 1000 px na dłuższym boku, małe litery i myślniki zamiast spacji, bez polskich znaków.

**Uwaga:** repozytorium jest publiczne. Nie umieszczaj tu ilustracji nieodkrytych artefaktów, ukrytych właściwości lub innych sekretów MG — nawet w nieużywanych plikach. Dodane obrazy należy później jawnie powiązać z istniejącym ID przedmiotu.
